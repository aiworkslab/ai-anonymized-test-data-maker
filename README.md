# AI Anonymized Test Data Maker / AI匿名テストデータメーカー

## Purpose / 目的

ExcelやCSVに含まれる実データを、AIへ相談しやすい汎用データへ置き換えるためのGUIツールです。

## Main Features / 主な機能

- 会社名、担当者名、商品名を汎用名へ置換
- 住所、電話番号、メールアドレスをダミーデータへ置換
- 得意先コード、部門コード、担当者コードを対応関係を保ったまま置換
- 請求書No.、伝票No.、行No.などの親子関係を保ったテストデータ作成
- Excel / CSV の読み込みと出力
- 最初はPC内だけで処理するローカルGUI版

## First Goal / 最初の目標

ExcelまたはCSVを読み込み、指定した列を匿名化して、
別ファイルとして出力できる最初のGUI版を作る。

## Version 0.1 Target Columns / Ver0.1で対応する列

最初のGUI版では、次の列を選んで匿名化できるようにする。

- 会社名
- 担当者名
- 商品名
- 住所
- 電話番号
- メールアドレス

同じ元データは、同じ匿名データへ置き換える。

例：
- 株式会社サンプル → 株式会社A
- 田中太郎 → 担当者001
- sample@example.com → user001@example.test

## Output File Rule / 出力ファイルのルール

元ファイルは上書きしない。

匿名化したファイルは、元ファイル名・作成日・連番を付けた別ファイルとして保存する。

形式：

`元ファイル名_YYYYMMDD_連番_anonymized.拡張子`

例：

- `取引先一覧_20260706_001_anonymized.xlsx`
- `取引先一覧_20260706_002_anonymized.xlsx`
- `取引先一覧_20260706_001_anonymized.csv`

同じ日に同じ元ファイルを複数回処理した場合、連番を `001`、`002`、`003` のように増やす。

## Column Selection Rule / 列選択ルール

ファイルを読み込んだ後、画面に表示された列名から、匿名化する列を選ぶ。

Ver0.1では、匿名化の種類ごとに選べる列は1つだけとする。

- 会社名として匿名化する列：1列
- 担当者名として匿名化する列：1列
- 商品名として匿名化する列：1列
- 住所として匿名化する列：1列
- 電話番号として匿名化する列：1列
- メールアドレスとして匿名化する列：1列

匿名化しない種類は、未選択にできるようにする。

例：

- 会社名として匿名化する列：得意先名
- 担当者名として匿名化する列：担当者
- 商品名として匿名化する列：商品名
- 住所として匿名化する列：未選択

## Mapping Rule / 対応関係のルール

Ver0.1では、匿名化を実行している間だけ、元データと匿名データの対応関係を保持する。

同じ元データは、同じ匿名データへ置き換える。

例：

- 株式会社サンプル → 会社001
- 株式会社サンプル → 会社001

匿名化処理が完了した後は、元データと匿名データの対応表ファイルは保存しない。

そのため、別の日に同じファイルを匿名化した場合、前回と同じ匿名データになる保証はない。
